# CodeTracker

A dashboard for competitive programmers to track their problem-solving progress across different platforms like LeetCode, Codeforces, CodeChef, and CSES.

## How to deploy on Vercel

The application is structured to be easily deployed on Vercel as a full-stack project utilizing Vercel's serverless functions for the Express backend and the standard Vite build process for the frontend.

### Fixing Google Login on Vercel
By default, the Firebase project configuration generated by AI Studio limits Google Sign-in exclusively to its specific preview domains. If you attempt to log in using the popup on Vercel, it will fail with an **Unauthorized Domain** error in Firebase.

To fix this, you must configure your **own Firebase Firebase Project** for Vercel:

1. Head over to the [Firebase Console](https://console.firebase.google.com/) and create a new project.
2. Under "Authentication" in your Firebase console:
   - Enable the **Google login** provider.
   - Go to the **Settings** tab.
   - Go to **Authorized domains**.
   - Add your Vercel app's domain (e.g., `your-app.vercel.app`).
3. Under "Firestore Database" in your Firebase console:
   - Create a new Firestore database (Native mode/production).
   - Go to the **Rules** tab of your Firestore Database.
   - You **MUST** paste the contents of `firestore.rules` (from this repository) into the Rules editor and click **Publish**. Otherwise, your app will get "Missing or insufficient permissions" errors.
4. Go to project settings, register a web app, and get your Firebase API keys.
5. In your **Vercel Project Dashboard**, go to **Settings > Environment Variables**, and add the corresponding fallback credentials shown below.

**Required Vercel Environment Variables:**
*   `VITE_FIREBASE_API_KEY`
*   `VITE_FIREBASE_AUTH_DOMAIN`
*   `VITE_FIREBASE_PROJECT_ID`
*   `VITE_FIREBASE_STORAGE_BUCKET`
*   `VITE_FIREBASE_MESSAGING_SENDER_ID`
*   `VITE_FIREBASE_APP_ID`
*   `VITE_FIREBASE_DATABASE_ID` (if you are utilizing custom databases, otherwise Firebase uses `(default)`)

> **CRITICAL: You MUST redeploy your Vercel app after adding these environment variables!** Vite bakes environment variables into the frontend during the build process. If you added the variables after your first deployment, your app is still using the old config. Go to your Vercel Dashboard -> Deployments -> click the three dots on your latest deployment -> **Redeploy**.

Once you redeploy with these environment variables, the codebase will automatically prioritize them over the built-in AI Studio config, enabling Login capabilities on your Vercel domain!

### One-Click Deploy
You can deploy this project directly to Vercel by pushing your code to a GitHub repository and importing it into Vercel.

### Step-by-Step Vercel Deployment

1. **Push your code to GitHub (or GitLab/Bitbucket)**
   Initialize a git repository if you haven't already:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin <your-repo-url>
   git push -u origin main
   ```

2. **Import into Vercel**
   - Go to your Vercel Dashboard (https://vercel.com/dashboard)
   - Click **Add New...** > **Project**
   - Import the repository you just pushed.
   
3. **Configure Project**
   - Vercel should automatically detect the framework as **Vite**.
   - Make sure the Build Command is `npm run build` or `vite build` (Vercel's default for Vite).
   - The Output Directory should automatically be set to `dist`.

4. **Environment Variables Config Details (If applicable)**
   - If your project requires any Firebase credentials, you must add them in the **Environment Variables** section before deploying. 

5. **Deploy!**
   - Click the "Deploy" button.
   - Vercel will build the frontend and set up the Express API automatically. The `vercel.json` file ensures that API routes are mapped correctly and client-side routing works as expected.

Once the build finishes, you'll be given a public URL where your application is live!
